# My Zsh Setup

I use [Oh My Zsh](https://ohmyz.sh/) as my Zsh framework. To install it, follow the instructions on the [Oh My Zsh website](https://ohmyz.sh/).

> \[!NOTE]
> I usually install Zsh with [Homebrew](https://brew.sh/):
>
> ```bash
> brew install zsh
> ```

After installation, pick a theme from the [Oh My Zsh themes list](https://github.com/ohmyzsh/ohmyzsh/wiki/Themes) and set it in your `.zshrc` file. For example:

```bash
ZSH_THEME="josh"
```
